# Student Data Processor & Segregation API with Gemini Insights

A FastAPI backend application that processes student performance datasets, normalizes student records, segregates students into performance brackets, and generates personalized AI academic insights using the Google Gemini API (`google-genai`).

## 🔑 Environment & Gemini API Key Setup

The application uses `python-dotenv` to automatically load environment configuration at startup:
- Place your `GEMINI_API_KEY` in the `.env` file (or `api.env` file) located in the root directory:
  ```env
  GEMINI_API_KEY=your_gemini_api_key_here
  ```
- When `main.py` and `app/insight.py` execute, `python-dotenv` loads `GEMINI_API_KEY` directly from `.env` into Python's `os.environ`.
- The official `google-genai` client initializes using `genai.Client(api_key=GEMINI_API_KEY)` and queries `gemini-2.0-flash`.

## 🚀 Getting Started

### 1. Install Dependencies
Install all required Python packages using `pip`:

```bash
pip install -r requirements.txt
```

### 2. Run Data Loader Script
Extract, clean, and normalize all student records from `assets/` into a single combined file saved as `assets/combined_students.csv`:

```bash
python data_loader.py
```

### 3. Start the FastAPI Server
Launch the server using `uvicorn` with hot-reload enabled:

```bash
uvicorn main:app --reload
```

The server runs locally at [http://127.0.0.1:8000](http://127.0.0.1:8000).

## 📊 Performance Brackets

Students are classified into three performance brackets according to their overall percentage score:

| Performance Bracket | Classification Label | Percentage Range |
|---|---|---|
| **Group A** | Advanced | `85.0%` to `100.0%` |
| **Group B** | Intermediate | `70.0%` to `84.99%` |
| **Group C** | Foundational Support | Below `70.0%` |

## 🔌 API Endpoints & Sample cURL Commands

### 1. Health Check (`GET /health`)
Verify API status and service health.

**cURL Command:**
```bash
curl -X GET "http://127.0.0.1:8000/health"
```

---

### 2. Segregate Combined Dataset (`POST /segregate/dataset`)
Processes `assets/combined_students.csv` and returns a grouped breakdown with student counts and complete lists per bracket.

**cURL Command:**
```bash
curl -X POST "http://127.0.0.1:8000/segregate/dataset"
```

---

### 3. Segregate Custom Upload (`POST /segregate/custom`)
Upload a custom CSV file to receive real-time bracket segregation.

**cURL Command:**
```bash
curl -X POST "http://127.0.0.1:8000/segregate/custom" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@assets/combined_students.csv;type=text/csv"
```

---

### 4. Personalized Academic Insight (`POST /student/insight`)
Searches `assets/combined_students.csv` for a student by `full_name`, retrieves their overall percentage score and performance bracket, and queries Google Gemini API (`gemini-2.0-flash`) to generate a 3-bullet-point academic report.

**cURL Command:**
```bash
curl -X POST "http://127.0.0.1:8000/student/insight" \
  -H "Content-Type: application/json" \
  -d "{\"full_name\": \"Armando Pollich PhD\"}"
```

**Expected Response Sample:**
```json
{
  "full_name": "Armando Pollich PhD",
  "overall_percentage": 59.6,
  "group": "Group C (Foundational Support)",
  "academic_insight": "- Current Performance & Strengths: Shows foundational potential with an overall score of 59.6%.\n- Recommended Extra Class Focus Areas: Prioritize core subject fundamentals through remedial support sessions.\n- Motivational Action Plan: Maintain a structured study schedule and track progress weekly."
}
```
